
## Pretrained Models

The trained model checkpoints are not included directly in this repository because they exceed GitHub's standard file size limit.

The pretrained models can be accessed from the following Google Drive folder:

https://drive.google.com/drive/folders/1xFy8NUJ0nKHwxgmHZoeJb75N-8sC99OV?usp=sharing

After downloading the checkpoints, place them in the corresponding model/checkpoint folders before running the demo or evaluation scripts.
